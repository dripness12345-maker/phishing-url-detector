How It Works

The Phishing URL Detector executes a multi-layer heuristic evaluation pipeline completely in your browser. Every submitted link is inspected across six specialized detection modules:

MODULE 01

Typosquatting Detection

Detects when URLs imitate popular brands using character substitutions like paypa1.com instead of paypal.com, homographs, or edit distance variations.

MODULE 02

Brand Impersonation

Identifies when real brand names appear in suspicious positions within URLs, such as deceptive subdomains (paypal.evil-site.com) or combinations with urgent action keywords.

MODULE 03

TLD Analysis

Analyzes domain extensions — high-risk TLDs like .tk, .ml, and .xyz receive elevated risk penalties due to their heavy association with disposable malicious hosting.

MODULE 04

URL Structure Analysis

Examines URL length, path segment depth, embedded redirect parameters (e.g. redirect=), excessive hyphens, and obfuscated percent-encoding tricks.

MODULE 05

Phishing Pattern Library

Matches URLs against known phishing patterns including credential harvest login forms, fake account verification notices, lottery lures, and urgency triggers.

MODULE 06

Smart Scoring System

Combines all module scores into a final 0–100 risk rating with a detailed pass/fail breakdown categorized as Safe, Low Risk, Suspicious, High Risk, or Critical.

Recent Analysis History

Shows the last 5 URLs analyzed during your current browser session. Stored in local sessionStorage for privacy.
